# 转义字符 `\`

```
var x = 'It\'s alright';
var y = "He is called \"Johnny\"";
```

## 1、`\'` 单引号转义

- 字符串用**单引号 `'`**包裹的时候，字符串内部又想写一个单引号 `'`，必须加反斜杠 `\` → `\'`

```
var x = 'It\'s alright';
//输出：It's alright
```

> 如果不写反斜杠： `var x = 'It's alright'` ❌ JS会认为字符串在 `It` 后面就结束了，直接语法报错。

## 2、`\"` 双引号转义

- 字符串用**双引号 `"`**包裹，字符串内部要出现双引号，用 `\"`

```
var y = "He is called \"Johnny\"";
//输出：He is called "Johnny"
```

> 不转义就报错：`"He is called "Johnny""` JS读到第二个 `"` 就判定字符串结束。

---

## 小规律

1. **外面用单引号 `' '`，里面直接写双引号不用转义**

```
var str = 'He is called "Johnny"'; // ✅正常，不用\
```

2. **外面用双引号 `" "`，里面直接写单引号不用转义**

```
var str = "It's alright"; // ✅正常，不用\
```

✅推荐写法，能不写转义就不写：

```
var x = "It's alright";
var y = 'He is called "Johnny"';
```

### 常用转义字符

|转义|含义|
|---|---|
|`\'`|单引号|
|`\"`|双引号|
|`\\`|输出反斜杠本身|
|`\n`|换行|

### 打印看效果

```
console.log(x); // It's alright
console.log(y); // He is called "Johnny"
```

## JS字符串转义 \
1. 字符串边界符号，内部出现相同符号，需要`\`转义
- `\'` 在单引号字符串内部输出单引号
- `\"` 在双引号字符串内部输出双引号

```js
var x = 'It\'s alright';
var y = "He is called \"Johnny\"";
console.log(x) // It's alright
console.log(y) // He is called "Johnny"
````

> 技巧：外面单引号，里面随便写双引号；外面双引号，里面随便写单引号，可以避免转义。

```
var x = "It's alright";
var y = 'He is called "Johnny"';
```
