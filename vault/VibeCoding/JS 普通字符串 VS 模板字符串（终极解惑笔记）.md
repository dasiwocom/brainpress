# JS 普通字符串 VS 模板字符串（终极解惑笔记）

## 1\. 最核心真理（你刚才卡住的点）

**单引号 / 双引号 = 纯文本容器**

**反引号模板字符串 = 可解析代码的容器**

### 重点一句话：

**只要在单/双引号里面，所有内容一律当成普通文字，不会识别变量、不会执行代码。**

---

## 2\. 为什么双引号不能用 $\{变量\}？

举例证明：

```Plain Text
let name = "小明"

// 双引号：${name} 只是普通文字，不解析变量
let str1 = "我是${name}"
console.log(str1) 
// 输出：我是${name}

```

双引号眼里：

- `$` 就是符号

- `{` 就是括号

- `name` 就是四个普通字母

**它完全不知道这是变量**

---

## 3\. 只有反引号 \`\` \` \`\` 才有魔法

反引号专门开启「解析模式」

```Plain Text
let name = "小明"

let str2 = `我是${name}`
console.log(str2)
// 输出：我是小明

```

反引号眼里：

- 遇到 `${}` 就自动当成 **JS代码** 执行

- 取出变量真实值替换进去

---

## 4\. 双引号想用变量只能用「加号拼接」

双引号没有解析功能，只能拆字符串拼变量：

```Plain Text
let str3 = "我是" + name

```

---

## 5\. 三者终极区别对照表（必背）

|包裹符号|是否解析 $\{变量\}|是否支持直接换行|本质|
|---|---|---|---|
|单引号 `' '`|❌ 不解析，纯文本|❌ 不能换行|普通字符串|
|双引号 `" "`|❌ 不解析，纯文本|❌ 不能换行|普通字符串|
|反引号 `` ``|✅ 解析变量/表达式|✅ 随意换行|模板字符串|

---

## 6\. 你之前的疑惑总结（完全解答）

**疑问：我把反引号换成双引号，看着也没错啊？**

**答案：**

看着没错，但是 **功能废了**。

双引号不会解析 `${}`，只会原样打印字符，读不到变量的值。

## 7\. 极简口诀

- **单双引号：只存字，不干活**

- **反引号：能解析，能换行，能插变量**
