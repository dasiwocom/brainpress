## 百度SEO网站介绍文案生成规范（CSV批量导入版）

### 一、核心执行规则（必须100%严格遵守）

1. **整体用途**：专门生成**适配百度SEO、原创度高、自然埋词、收录友好**的网站介绍文案，用于站点收录、资源分享页面，杜绝关键词堆砌、机器感、重复口水话。
2. **输出格式**：**CSV单行格式**，包含五个表头（标题、别名、简介、图片链接、发布状态），用户直接复制粘贴进后台「CSV批量导入」文本框，点击「开始导入」即可。
3. **标题格式**：网站名称 | 简短核心描述（总字符15–35字，自然流畅，包含网站核心主关键词，不卡点、不生硬）。**此标题仅作为WordPress文章标题（H1），不再出现在正文简介中**，避免与模板重复渲染。
4. **别名规则**：从图片链接中的网址标识提取，将所有 `.` 替换为 `_`。例如图片链接含 `www.thiings.co`，则别名为 `www_thiings_co`。
5. **正文要求**：字数固定**400–500字**，分段清晰（2-3段），逻辑层层递进，适配搜索引擎收录逻辑，语句通顺、原创、客观详实。
6. **排版格式**：正文结束后**空两行**，最后一行固定格式：`官方网站：<a href='完整HTTPS网址' target='_blank'>完整HTTPS网址</a>`。**HTML标签必须使用单引号**，避免与CSV外层双引号冲突导致显示异常引号。
7. **禁止内容**：不加图片、不加符号、不加特殊格式、不写主观夸张吹捧话术、不重复啰嗦，全程客观专业。
8. **SEO核心逻辑**：首段定义网站定位，中段详细讲功能、优势、适配人群，尾段总结使用价值，**自然植入核心关键词+长尾关键词**，密度合理，适配百度收录排名。

### 二、固定行文结构（强制统一）

1. **第一段**：开门见山，点明网站**核心定位、主打功能、核心特点**（免安装、免费、在线使用、专属场景等），匹配用户核心搜索意图。
2. **第二段**：详细拆解网站**功能分类、核心优势、安全特点、页面体验、设备适配**，细化使用场景。
3. **第三段**：总结**适用人群、使用价值、替代优势**，点明解决用户的实际痛点，拔高实用性。
4. **结尾**：空两行，放置HTML超链接格式的官方网址。

### 四、用户后台模板适配说明

用户WordPress后台「文章模板设置」格式为：
```html
<h2>{{title}}</h2>
<p>{{intro}}</p>
<p><img src="{{img_url}}" alt="{{title}}" /></p>
```

因此：
- **标题列** = `{{title}}`，由模板渲染为 `<h2>`，**简介列严禁再写标题文字**，防止页面上标题重复出现。
- **简介列** = `{{intro}}`，由模板渲染为 `<p>` 段落，**只放纯正文**。
- **图片链接列** = `{{img_url}}`，由模板自动插入文章配图。

### 六、操作流程（用户侧）

1. 用户发送**图片外链**（如 `https://www.dasiwo.com/.../www_xxx_com.webp`）
2. AI识别网站 → 按规范生成SEO文案 → 输出完整CSV单行
3. 用户**完整复制CSV内容** → 粘贴进后台「CSV批量导入文章」文本框
4. 点击「开始导入」→ 自动生成带标题、正文、配图、官网链接的标准SEO文章

### 七、关键注意事项

- **HTML单引号强制规则**：`<a href='...' target='_blank'>` 必须用单引号，否则CSV解析会在链接右侧残留 `"`。
- **标题去重强制规则**：简介列绝对禁止出现标题文字，标题仅存在于「标题」表头。
- **别名提取规则**：只看图片链接里的网址主体，去掉协议头，`.` 全换 `_`，不保留路径和文件后缀。
- **字数控制**：简介列正文严格控制在400-500字（不含官网链接HTML代码），导入前可自行粘贴到字数统计工具校验。
